# Backgammon / Нарды

[English](#eng) | [Українська](#ukr) | [Русский](#rus)

---

<a id="eng"></a>
## English

A local co-op long backgammon (narde) game made in Unity.

### About
Two players take turns on the same device.

### Controls
- **Click** a checker to select it
- **Click** a highlighted cell to move
- **Escape** to cancel selection

<a id="ukr"></a>
## Українська

Локальна кооперативна гра в довгі нарди, зроблена на Unity.

### Про гру
Два гравці ходять по черзі на одному пристрої.

### Керування
- **Клік** по шашці — вибір
- **Клік** по підсвіченій клітинці — хід
- **Escape** — скасувати вибір

---

<a id="rus"></a>
## Русский

Локальная кооперативная игра в длинные нарды, сделанная на Unity.

### Об игре
Два игрока ходят по очереди на одном устройстве.

### Управление
- **Клик** по шашке — выбор
- **Клик** по подсвеченной клетке — ход
- **Escape** — отменить выбор
