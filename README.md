# Backgammon

An open-source Long Backgammon game built with Unity.

## Features

- Long Backgammon rules
- Local multiplayer
- Move highlighting
- Illegal move prevention

## Controls

| Action | Input |
|--------|-------|
| Select checker | Left Mouse Button |
| Move checker | Left Mouse Button |
| Cancel selection | Esc |
